## Long-term — only if the portfolio earns it

### A real project showcase

- [ ] **Per-project tag filtering** on the projects section (AI / Web /
      Data). Adds JS, adds a UX surface to maintain.
- [ ] **Search** across posts. Probably overkill for ~10 posts; revisit
      at 30+.

### A real blog

- [ ] **Decap CMS or Sanity** behind the `_posts/` directory. Adds an
      editor surface; not worth doing without a writing pattern.
- [ ] **RSS/Atom feed** is already generated by `jekyll-feed`. Promote
      the `feed.xml` link more visibly if writing volume picks up.

### Bigger ideas

- [ ] **A live AI demo** — a tiny on-page agent or RAG demo that runs
      against a small dataset. Only valuable if it's real and
      maintainable, not a tech demo.
- [ ] **Dynamic case studies** — embed a live Power BI page if the
      Aurora project's hosted version becomes shareable.

## Things explicitly **not** on this roadmap

- Light/dark mode toggle. Declined.
- Custom cursor / magnetic hover / card tilt / Konami code. Declined.
- Service worker. Declined.
- Page-fade transitions. Declined.
- Skill percentage bars. Declined; tiers in use instead.
- LinkedIn live API integration. Closed API; not worth the partner
  programme overhead.
- A chatbot version of "Paul". Reads as a tech demo, not as evidence.

Each declined item has reasoning preserved in
`docs/integrations-and-mcps.md` or in the relevant phase 2 commit
messages.
