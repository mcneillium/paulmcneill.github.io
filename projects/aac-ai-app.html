AI-Powered AAC App

Assistive communication for non-verbal users with on-device AI prediction and a real-time caregiver dashboard.

  • React / React Native
  • TensorFlow.js
  • Firebase
  • WCAG 2.1 AA
  • GDPR-first

Project Overview

I designed and built an AI-enhanced Augmentative & Alternative Communication (AAC) system: a mobile app that suggests words and symbols using on-device TensorFlow.js, paired with a Firebase-backed caregiver dashboard for real-time insights. The interface follows WCAG 2.1 AA guidance and a GDPR-first data model with role-based access.

  • Predictive suggestions (sub-second) on device; works offline
  • Real-time logs and analytics for caregiver visibility
  • High-contrast UI, large touch targets, screen-reader support
  • Role-based permissions to preserve user autonomy
← Back to Analytics

The Problem

  • Static AAC vocabularies slow message creation
  • Limited caregiver insight into usage and progress
  • Privacy concerns with cloud-only AI approaches

The Solution

  • On-device AI (TensorFlow.js) for next-word predictions
  • Firebase dashboards for live analytics & exports
  • WCAG-compliant UI; large tap targets; contrast modes
  • Role-based access (user, caregiver, admin); minimal data collection

The Impact

  • Faster message composition; reduced cognitive load
  • Caregivers spot trends and intervene proactively
  • Privacy preserved (offline-first, least-privilege rules)

Screens & Artifacts

Mobile sentence builder – predictive suggestions and TTS.

Accessibility – high contrast, large controls, screen reader cues.

Real-time logs – dashboard charts & CSV export.

Architecture & Tooling

  • React Native (app), React (dashboard)
  • TensorFlow.js (quantised model; worker-thread inference)
  • Firebase Auth & Realtime DB (role-based rules)
  • Charting for usage insights; CSV exports

Ethics, Privacy & Accessibility

  • GDPR-aligned: data minimisation; explicit consent flows
  • Least-privilege RBAC; no sensitive screenshots
  • WCAG 2.1 AA: contrast, semantics, focus order, labels
