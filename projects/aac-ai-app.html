AI-Powered AAC App

Assistive communication for non-verbal users with predictive AI and a real-time caregiver dashboard.

  • TensorFlow.js
  • Firebase
  • React / React Native
  • WCAG 2.1 AA

Project Overview

This project originated from my Open University final year work, inspired by my brother who has autism. It combines accessible design and AI to enhance communication for non-verbal individuals. The app suggests words using on-device TensorFlow.js AI and synchronises usage data with a Firebase caregiver dashboard for real-time monitoring.

  • Predictive next-word generation powered by TensorFlow.js
  • Offline-first design with local model inference
  • Real-time caregiver insights via Firebase analytics
  • GDPR-compliant and WCAG 2.1 AA accessible interface

Problem

Conventional AAC tools are static, slow, and offer little feedback to caregivers. Many rely on cloud-based AI, creating privacy risks for vulnerable users.

Solution

Created an offline-capable AI system using TensorFlow.js to generate next-word suggestions locally. Added a real-time dashboard for caregivers, with anonymised logs and predictive usage trends.

Impact

Enabled faster communication for users, reduced caregiver workload, and protected sensitive data with ethical, privacy-by-design principles.

Screens & Features

Sentence builder: predictive suggestions and text-to-speech playback.

Accessibility: high contrast, adjustable grid size, screen reader support.

Caregiver dashboard: live analytics via Firebase, tracking engagement and trends.

Tech Stack

  • React / React Native
  • TensorFlow.js (custom word prediction model)
  • Firebase (Auth, Realtime Database, Hosting)
  • WCAG 2.1 AA accessibility standards

Ethics & Accessibility

  • GDPR-compliant and privacy-by-design
  • Role-based access and data minimisation
  • Inclusive UX with large touch zones
